# 分析方案 v1.0：结果揭盲前冻结版

拟定日期：2026-09-21；最终审查与冻结日期：2026-09-23。本版替代 v0.2 的待定规则，保留全部历史版本。完成范围是队列、定义、实现、合成验证与空结果表；**尚未计算真实患者的 AKI 研究标签、分箱切点、标签变化或效果区间**。冻结散列见 `freeze-manifest.json`。

## 1. 题目、目标与文章类型

暂题：**数值分箱对术后肌酐急性肾损伤研究标签的影响：两个公共手术数据库的配对方法学研究**。

比较同一患者同一组采样时刻，仅改变已发布肌酐数值的表示方式后，观察性研究中的 SCr 标签是否改变。文章为经验方法学原著；不建预测模型，不评价治疗因果效应，不作完整临床 AKI 诊断验证。原始公开值是计算参照，非仪器真值、病历确诊或临床金标准。

主要估计对象为两个既定公开队列内的配对标签不一致比例；中心分开，不计算合并主效应。不同地区、中心与原始数值格点使独立规则复现有价值，但不保证可推广到其他医院。数值转换是依据公开原则规定的自定义实验，不声称精确恢复 INSPIRE 的完整处理代码，不把结果解释为隐私安全程度。


## 2. 数据身份与来源（本地路径和授权记录已移除）

- MOVER EPIC：`mover-epic@epic-snapshot-2026-07-20`，原注册的三个归档；本阶段从 `EPIC_EMR.tar.gz` 重新提取患者信息、LOINC 2160-0 mg/dL 检验与同手术就诊诊断。没有使用 SIS、波形版本或跨手术无日期 history 表。
- VitalDB：`vitaldb-clinical-labs@1.0.0`，官方1.0.0发布的 clinical_data、lab_data 和两个参数字典；仅临床/检验子集，不代表整个波形库。

## 3. 固定人群与排除顺序

每个库先按完整发布临床表计算每位患者的不同手术数。只保留库内仅一例手术者，再筛成人、全麻及有效起止时间；不能为获得更完整化验选择某次手术。MOVER 的 `BIRTH_DATE` 字段在此发布快照体现17–90的年龄编码，按前期核对的年龄解释，90单列顶端编码；VitalDB `>89` 用于成人资格与顶端编码，不伪造精确年龄90。

MOVER 对同一 LOG_ID 的身份、年龄、麻醉类型、术名、麻醉及入出院时间任一冲突整例排除，之后病例号唯一。所有记录同时要求 LOG_ID/MRN 一致；VitalDB clinical.caseid 唯一，由 subjectid 识别重复患者。麻醉开始/结束必须有效且后者大于前者；入院不晚于麻醉开始，出院不早于麻醉结束。时长超过24小时在主分析保留，但预定敏感性排除。

共同临床范围为成人全麻的非心脏手术及操作。`results/procedure-map.csv` 为完整 exact-name 决策清单（2,010个术名），只纳入 include，exclude与uncertain均排除。心脏本体/冠脉/瓣膜、心律装置与电生理、心包及独立诊断性心脏操作被排除；胸肺、外周血管、明确非心脏部位保留。泛称、AV access和用途未明导管单列含糊类别，不称确诊透析。VitalDB原始队列的非心脏限制可支持其泛称术名；MOVER无同等来源限制，部位不明的泛称保守排除。这个来源差异保留在局限中。

显性肾移植/透析相关术式由术名映射排除。再依据 `results/diagnosis-map.csv` 的 code+term（MOVER）或term（VitalDB）排除明确 ESRD、慢性透析依赖、肾移植受者状态/并发症和明确但慢性/急性时间不明的RRT状态；后者单列uncertain。普通 CKD、CKD5、AKI、CKD5或ESRD的二义描述、供者记录不自动排除。MOVER仅采用同LOG_ID+MRN的patient_visit；不借助无时间的跨病例病史排除患者。

诊断记录时间无法全部确定，不能称“已排除全部术前慢性肾病/透析”。本研究是记录定义的受限人群标签实验，非新发临床AKI发生率研究。“不采用诊断排除”的敏感性保留此选择的影响。既存AKI不以缺少记录推定不存在，也不使用术前AKI算法筛选本次人群。

本版最终主比较候选人群：**MOVER 4,321人；VitalDB 2,059人**。平行7天倍数规则人群：4,433人和2,540人。最终流程图在 `results/*-cohort-flow.csv`；这些是人群/时序计数，不是事件数。

## 4. 肌酐与观测时点

MOVER只用 LOINC 2160-0、mg/dL、身份匹配检验；VitalDB只用官方字典 cr（Chemistry/Creatinine/mg/dL），不混入ccr/gfr。VitalDB无逐条标本/LOINC，发布时删除非数值字符；不能恢复检出限语义，也不能证明每条标本完全等价。无时间戳的preop_cr不用于回溯判据。

原值读取条件：有限且 `0<SCr<100 mg/dL`、有效时间。它是宽松读取界限，不是生理有效性证明。共同全局记录窗口为 `[麻醉开始−7天, min(麻醉结束+7天,出院)]`，保留合法术中/术后记录作为后续时点的前值。先完全去重患者/时刻/数值；同一时刻多个不同值则去掉整个时刻，不默认取最大。冲突发生在全局窗外不影响此窗的敏感性标记。

术前 `[麻醉开始−7天,麻醉开始)` 至少一次检验为覆盖资格。目标术后时点为 `(麻醉结束,min(麻醉结束+7天,出院)]`。每次t的前值窗为 `[t−48小时,t)` 和 `[t−7天,t)`，同时不得越过全局窗口。前值采用窗口最低值，而非最近值；无前值是未观察，不是阴性。

主要E48集合仅含有48小时前值的术后时点，这些时点必然也有7日前值。患者E48非空才入主比较。原版和全部变换版共用固定患者、原始冲突处理、E和前值索引。E之外的检验不进入主要OR，但可作为后来E时点的合法前值。主要标签为E48中是否存在 `当前−48h最低值≥0.3` 或 `2×当前≥3×7d最低值`。没有E时输出None；在非空E内未满足规则的False只表示这组观测中未发现，不是完整7天无AKI。

平行7天分析使用E7非空且术前覆盖的人群，只用倍数判据，各自重新估计数值映射。它同时改变人群、判据和参考总体，不能把主次差值全部归因于删除48小时判据。

## 5. 四个固定数值版本

每个中心、每项预定分析分别以其固定合格患者的全部全局窗内、去重后测量为参考总体。记录等权，包含前值、术中及E外记录；不按阳性或检测结果决定参考总体。两个中心不共用切点。患者等权分位数在本版不执行；频繁检测患者贡献更多权重作为局限报告，避免在结果后增加有利版本。

令Q为type1经验逆分布分位数，M(x)为原参考分布的中秩，即低于x的频率加等于x频率的一半。

| 版本 | 预定定义 | 地位 |
|---|---|---|
| I | 原公开数值 | 计算参照 |
| T | 截断至Q(.025)、Q(.975)之间 | 次要对照 |
| B | x≤Q(.025)取低端，x≥Q(.975)取高端；其余按M(x)选择最近的.05,.10,…,.95节点，等距取低，输出对应Q；上下端相同则全取该值 | 唯一主要比较I对B |
| G | `max(0.2,0.2×floor(x/0.2+0.5))` | 固定格距对照，明确带正值下限 |

T/B参考分布均由原值估计，不先截断再重新分箱。不要求B与G具有相同隐私保护或支持点数量，不据此比较隐私安全。G低端额外上推必须报告触及下限的记录/患者数。任何变换后不得重新筛患者或数值；例如99.99转为100仍须保留。

关键比较用原始CSV数字字符串→Decimal/Fraction或精确整数cents，不采用浮点容差掩盖阈值差异。向量实现仅在所有原值×100严格为整数时启用，否则停止而非默默舍入。单调转换允许先计算原值窗口最低值再映射；等价性由合成测试核对。

## 6. 主要量、重抽样与解释

各中心分别报告I对B的患者四格表n00/n01/n10/n11，第一位是原值，第二位是变换值。唯一主要量为 `D=(n01+n10)/N`。预定解释量为两方向比例、原/变换阳性率及净变化 `(n01−n10)/N`。净差零不等于无个体变化。I对T、I对G及平行7天均为预定次要结果。不存在按P值升级主比较的选项。

主要点估计是固定公开队列的准确计算。补充对患者组成的**95%患者重抽样稳定性区间**：每库每项分析有放回抽N名患者，保留整人时序和重复副本权重；T/B每次重估Q/M，四版本同批权重；固定5000次，PCG64，SeedSequence(20260921)。中心子流固定MOVER、VitalDB；中心内再按main、parallel7、S1…S6的顺序派生8个子流，独立于文件遍历顺序。患者按来源中的case_id字符串字典序排序并记录。

区间用5000次统计量的type1第2.5/97.5百分位。保存每次结果和诊断，任何异常/分母不符立即停止，不能丢弃失败抽样后凑数。报告不同映射组合数、不同D值数和退化区间。零不一致仍执行全部流程；若出现[0,0]，注明重抽样退化，不宣称总体风险为零或等价。两中心不合并、不作预设之外的跨中心显著性检验。

离散分位数存在普通bootstrap失效的理论反例；本研究未证明此复杂标签函数的总体覆盖率，因此不把上述区间包装成保证95%覆盖的总体置信区间。T/B亦不附忽略切点估计依赖的“精确二项区间”。本版不另加入固定G的二项区间、P值、等价/非劣检验。方法依据与限制见独立统计审查及[Jentsch与Leucht原文](https://link.springer.com/article/10.1007/s10463-015-0503-3)。

## 7. 六项预定敏感性

每项分别重建参考人群/记录，内部四版本仍严格配对，重新估计T/B。

1. S1：不采用诊断排除；手术/操作排除保持。检验不明确诊断时间和记录完整性的影响。
2. S2：目标时点从麻醉结束后5分钟之后开始；首5分钟记录仍可作后来时点的合法前值，不能误写成全部删除。
3. S3：整人排除全局窗内任何SCr<0.1或>30；两端值本身保留，不只删改变标签的记录。
4. S4：整人排除麻醉时长>24小时；恰好24小时保留。
5. S5：整人排除全局窗内曾存在冲突时间戳者。
6. S6：仅保留全部已观察术后目标时点均属于E48者。它仍不代表完整连续7天监测。

不执行结果驱动的敏感性组合。队列构建过程中用于质量复核的“全部限制同时应用”人数仅为诊断性计数，不升级为额外效果分析。
